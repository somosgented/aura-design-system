01 / CAIRN BUILDS

Compile once, serve everywhere

Every push triggers a Benchwork build that produces an immutable cairn artifact. Instant rollback, zero drift between environments.

02 / BOT LANES

Isolated paths for every bot

Helper bots run in dedicated lanes with scoped credentials. They never touch your main cairn traffic, even when they hit rate limits.

Common questions

A cairn is a deployed project on Slatemoor — an immutable build artifact that is live, versioned and rollback-ready. Each push creates a new cairn; previous ones stay available for instant restoration. All figures in this page are sample data.
Bot lanes are isolated execution paths within your Slatemoor account. Each bot receives a scoped access key and runs in a sandboxed environment that cannot touch your main cairn traffic. Sample figures on this page are fictional.
Yes. The Benchwork CLI has a bench migrate command that imports your existing build config. Static sites, Node services and containerized apps are all supported. The first cairn is free regardless of plan.
One bot lane minute is 60 seconds of active execution time for a single bot task. Idle wait time between tasks is not counted. All plan limits shown are sample figures for illustration purposes.
