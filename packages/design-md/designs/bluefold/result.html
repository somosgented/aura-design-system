How it works

Small handoffs, clear receipts.

Six ideas that shape every run in this fictional product.

01 · Parallel

Several errands at once

Start a few briefs and let them run side by side instead of in a queue.

02 · Thread

One thread per task

Every run keeps its own status line, so you always know where it stands.

03 · Routine

Routines it picks up

Repeat a task twice and it offers to remember the steps for next time.

04 · Memory

Notes with a source

Anything it remembers shows where it came from, and you can delete it.

05 · Crew

Helpers that hand off

One helper drafts, another checks, and you see each handoff in the log.

06 · Trades

Built for small studios

Bookkeeping, scheduling and client follow-ups for people who run the whole shop.

FAQ

Questions, answered plainly.

Does it send anything without asking?

No. In this fictional product every outgoing message waits for your approval.

Can I see what it remembers?

Yes. Each note lists the run it came from and can be removed.

Does it work on my phone?

The layout is designed for desktop and pocket screens alike.

Is Bluefold a real product?

No. Bluefold is a sample context for an Aura design flavor.
