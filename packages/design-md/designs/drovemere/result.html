Drovemere Line

A nimble terminal tool built for people who live on the keyboard. Kick off shell errands, watch dry-run output stream live, and inspect patch summaries without touching a mouse.

drovemere-line · sample
$ drovemere errand "add retry guard" lane #3 ready · 2 files matched drover> updating src/fetch.ts - return callApi(req) + return withRetry(callApi, req, 3) checks: 14 passed · 0 warnings

Drovemere Bench

A focused code editor where every drover change lands beside your own cursor. Browse open lanes, read inline rationales, and accept individual hunks with confidence.
