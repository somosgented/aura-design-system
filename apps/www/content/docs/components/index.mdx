## All Components

Here is a complete list of all available components in the Aura Design System:

### [Accordion](./components/accordion)

A vertically stacked set of interactive headings that each reveal a section of content.

### [Action Bar](./components/action-bar)

A floating toolbar for bulk actions on selected items.

### [Alert](./components/alert)

Displays a callout for user attention with contextual feedback messages.

### [Alert Dialog](./components/alert-dialog)

A modal dialog that interrupts the user with important content and expects a response.

### [Angle Slider](./components/angle-slider)

A circular slider for selecting an angle or value along an arc.

### [App Bar](./components/app-bar)

A top bar in three sizes that gains a shadow when content scrolls under it.

### [Area Chart](./components/area-chart)

Area chart family — natural, linear, step, stacked, expanded, legend, icons, gradient, axes, and an interactive range.

### [Aspect Ratio](./components/aspect-ratio)

Displays content within a desired ratio.

### [Attachment](./components/attachment)

A file row with idle, uploading, success, and error states.

### [Autocomplete](./components/autocomplete)

A input component that allows users to search and select from a list of options.

### [Avatar](./components/avatar)

An image element with a fallback for representing the user.

### [Avatar Group](./components/avatar-group)

Overlapping avatars with truncation, orientation, and custom overflow.

### [Badge](./components/badge)

Displays a badge or a component that looks like a badge.

### [Badge Overflow](./components/badge-overflow)

Measures available space and shows badges with an overflow indicator.

### [Banner](./components/banner)

A full-width notice with an optional action and dismiss button.

### [Breadcrumb](./components/breadcrumb)

A navigation trail for the current page.

### [Bubble](./components/bubble)

Displays conversational content in a message bubble. Supports variants, alignment, grouping, reactions, and polymorphic content.

### [Button](./components/button)

Displays a button or a component that looks like a button.

### [Button Group](./components/button-group)

A container that groups buttons (and optional text or separators) with shared styling and orientation.

### [Calendar](./components/calendar)

Displays a calendar.

### [Card](./components/card)

Displays a card with header, content, and footer sections.

### [Carousel](./components/carousel)

A carousel component built with Embla, with optional previous/next controls and configurable orientation.

### [Chart](./components/chart)

Chart container, tooltip, and legend. Series colors use Aura chart tokens.

### [Checkbox](./components/checkbox)

A control that allows the user to toggle between checked and not checked.

### [Chip](./components/chip)

Standalone assist, filter, and input chips.

### [Circular Progress](./components/circular-progress)

Determinate progress drawn as a circle.

### [Collapsible](./components/collapsible)

An interactive component which expands and collapses content.

### [Color Picker](./components/color-picker)

A color field with a picker, a typed hex value, and swatches.

### [Color Swatch](./components/color-swatch)

A selectable color sample.

### [Combobox](./components/combobox)

A combobox component that allows users to search and select from a list of options.

### [Command](./components/command)

A command palette that allows users to search and execute commands.

### [Compare Slider](./components/compare-slider)

A slider that reveals one view over another.

### [Context Menu](./components/context-menu)

Displays a menu to the user triggered by right-click or long-press.

### [Cropper](./components/cropper)

A draggable crop region you can also nudge with the arrow keys.

### [Date Picker](./components/date-picker)

A single date chosen from Calendar inside a Popover.

### [Dialog](./components/dialog)

A window overlaid on the primary content, rendering content in a layer above the page.

### [Drawer](./components/drawer)

A drawer component that slides in from the edge of the screen.

### [Dropdown Menu](./components/dropdown-menu)

Displays a menu of actions or options triggered by a button.

### [Editable](./components/editable)

Inline text that switches between preview and edit modes.

### [Empty](./components/empty)

A placeholder component for empty states, with optional icon, title, description, and content slots.

### [Expressive Carousel](./components/expressive-carousel)

A carousel whose items resize as you scroll.

### [Fab](./components/fab)

A floating button for a screen's main action, with an optional label.

### [Fab Menu](./components/fab-menu)

A floating button that opens a stack of related actions.

### [Field](./components/field)

Standalone field layout that sits beside Form.

### [File Upload](./components/file-upload)

A composable file upload with dropzone, list, previews, and progress indicators.

### [Form](./components/form)

A comprehensive form system with schema-based validation, error handling, and field management. Built with Radix UI primitives and AJV validation, supporting text inputs, textareas, selects, checkboxes, switches, and checkbox groups with automatic error propagation and touch state management.

### [Fps](./components/fps)

A live frames-per-second meter.

### [Gauge](./components/gauge)

A semicircle meter with a needle.

### [Grid](./components/grid)

Displays a grid container with configurable column layout.

### [Hover Card](./components/hover-card)

For sighted users to preview content available behind a link.

### [Icon](./components/icon)

A wrapper for icons, including marks built with createIcon.

### [Input](./components/input)

Displays a form input field or a component that looks like an input field.

### [Input Group](./components/input-group)

Add addons, buttons, and helper content to inputs.

### [Input OTP](./components/input-otp)

A one-time code built from SegmentedInput.

### [Item](./components/item)

A list row with media, title, description, and actions.

### [Kanban](./components/kanban)

Columns of cards that move backward and forward.

### [Kbd](./components/kbd)

A keyboard shortcut component that allows users to display keyboard shortcuts.

### [Key Value](./components/key-value)

A list of labels and values.

### [Label](./components/label)

Renders an accessible label associated with form controls.

### [Listbox](./components/listbox)

A list of options with arrow-key selection.

### [Loading Indicator](./components/loading-indicator)

A loading status that morphs between shapes.

### [Marker](./components/marker)

Displays an inline status, system note, bordered row, or labeled separator in a conversation.

### [Marquee](./components/marquee)

A looping row of items that pauses for reduced motion.

### [Mask Input](./components/mask-input)

An input that formats values with built-in or custom mask patterns.

### [Masonry](./components/masonry)

A two-column layout that keeps items intact.

### [Media Player](./components/media-player)

Play, pause, seek, and mute controls for an audio source.

### [Mention](./components/mention)

An accessible text input that suggests and inserts items after a trigger character.

### [Menubar](./components/menubar)

A visually persistent menu common in desktop applications.

### [Message](./components/message)

Displays a message in a conversation, with optional avatar, header, footer, and alignment.

### [Message Scroller](./components/message-scroller)

A chat scroll container that anchors turns, follows streamed output, loads history without jumping, and jumps to any message.

### [Native Select](./components/native-select)

A native select with the same field chrome as other inputs.

### [Navigation Bar](./components/navigation-bar)

Bottom navigation for phones.

### [Navigation Menu](./components/navigation-menu)

A collection of links for navigating websites.

### [Navigation Rail](./components/navigation-rail)

Side navigation for tablet and desktop, collapsed or expanded.

### [Pagination](./components/pagination)

Pagination with page links, previous/next controls, and ellipsis.

### [Phone Input](./components/phone-input)

A phone field with a calling code and a typed number.

### [Popover](./components/popover)

Displays rich content in a portal triggered by a button.

### [Presentation](./components/presentation)

Composable PowerPoint viewer and editor built on @diceui/pptx.

### [Progress](./components/progress)

Displays an indicator showing the completion progress of a task.

### [Qr Code](./components/qr-code)

A square code for a short string, up to 17 bytes.

### [Questionnaire](./components/questionnaire)

One question at a time, built on Stepper.

### [Radio Group](./components/radio-group)

Re-usable components built using Radix UI and Tailwind CSS.

### [Rating](./components/rating)

A star rating that works with the keyboard.

### [Relative Time Card](./components/relative-time-card)

A relative time with the absolute date beside it.

### [Resizable](./components/resizable)

Panels that resize by drag or keyboard.

### [Responsive Dialog](./components/responsive-dialog)

A dialog on desktop and a drawer on mobile, sharing one API.

### [Responsive Dropdown Menu](./components/responsive-dropdown-menu)

A dropdown menu on desktop and a stacked drawer for nested menus on mobile.

### [Scroll Area](./components/scroll-area)

Augments native scroll functionality for custom cross-browser styling.

### [Scroll Spy](./components/scroll-spy)

A list of links that marks the section in view.

### [Scroller](./components/scroller)

A horizontal strip with back and forward controls.

### [Search](./components/search)

A search bar that expands into a results view.

### [Section](./components/section)

A semantic section container with configurable layout variants.

### [Segmented Input](./components/segmented-input)

A group of connected input fields that appear as a single segmented visual unit.

### [Select](./components/select)

A select component that allows users to select a value from a list of options.

### [Selection Toolbar](./components/selection-toolbar)

A floating toolbar that appears on text selection with formatting and utility actions.

### [Separator](./components/separator)

A separator component that allows users to separate content.

### [Shape](./components/shape)

A set of shapes that can mask an image and morph between each other.

### [Sheet](./components/sheet)

A slide-out panel that overlays the page, with optional header, footer, title, and description. Opens from a trigger (e.g. button).

### [Side Sheet](./components/side-sheet)

A side panel that sits beside the content, with no overlay.

### [Sidebar](./components/sidebar)

A collapsible side panel for app navigation and layout, with optional mobile sheet, icons, and persistent state.

### [Signature Pad](./components/signature-pad)

A component that allows the user to sign a document using a pen.

### [Skeleton](./components/skeleton)

A loading placeholder with pulse animation, typically used for content that is being fetched.

### [Slider](./components/slider)

An input where the user selects a value from within a given range.

### [Snackbar](./components/snackbar)

A short message at the bottom of the screen with one optional action.

### [Sortable](./components/sortable)

A sortable list of items.

### [Speed Dial](./components/speed-dial)

A floating button that opens a stack of actions. Same parts as the floating action menu.

### [Spinner](./components/spinner)

A status spinner reused by Button and FormSubmit.

### [Split Button](./components/split-button)

A main action paired with a menu of related actions.

### [Stack](./components/stack)

Overlapping panels offset from one another.

### [Stat](./components/stat)

Displays a statistic with label, value, optional indicator, trend, and description.

### [Status](./components/status)

A short status label with a tone dot.

### [Stepper](./components/stepper)

A sequential progress indicator with navigation controls.

### [Swap](./components/swap)

Switches between two views in place.

### [Switch](./components/switch)

A control that allows the user to toggle between on and off states.

### [Table](./components/table)

A responsive table for organizing related data into rows and columns.

### [Tabs](./components/tabs)

A tabs component that allows the user to switch between different views.

### [Tags Input](./components/tags-input)

A field that collects tags. Enter adds one, Backspace removes the last.

### [Textarea](./components/textarea)

A multi-line text input for longer form content.

### [Time Picker](./components/time-picker)

A clock dial paired with a typed time field.

### [Timeline](./components/timeline)

A vertical list of titled moments.

### [Toast](./components/toast)

How to install sileo and style it with Aura tokens. Aura does not ship a Toast component.

### [Toggle](./components/toggle)

A toggle component that allows the user to toggle between on and off states.

### [Toggle Group](./components/toggle-group)

A group of toggle buttons where one or more options can be selected, with single or multiple selection modes.

### [Toolbar](./components/toolbar)

An always-visible bar of related actions.

### [Tooltip](./components/tooltip)

A tooltip component that displays informative text when hovering over an element.

### [Tour](./components/tour)

A short stepped guide that highlights one target at a time.

### [Typography](./components/typography)

The fluid type scale as CSS classes. Aura does not ship a Typography component.
