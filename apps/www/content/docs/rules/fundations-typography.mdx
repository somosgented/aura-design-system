# Typography guardrails

## Installation
```bash
pnpm dlx shadcn@latest add @aura/rule-fundations-typography
```
Scale tables and formula live in `DESIGN.md` §3. This rule only constrains agent behavior.

* **MUST**: Size primary type with `clamp(var(--min), var(--val), var(--max))` via `h1`–`h6` / `.h1`–`.h6` / `p` / `.p`.
* **NEVER**: Use Tailwind `text-xl`, `text-2xl`, `text-4xl`, etc. for primary copy.
* **EXCEPTION**: `text-sm` / `text-xs` for fixed utility/meta text only — **never** on editable `input` / `textarea` / `select`.
* **MUST**: Editable form controls stay **≥ 17px** (`max(1rem, 17px)` or inherit the 17px root). Enforce globally in CSS (`styles/main.css` / unlayered globals), not only per component.
* **SHOULD**: Keep `html { font-size: 17px; }` so `1rem` already meets the floor.
* **MUST**: Use `rem` for `--min` / `--max`. Large headings SHOULD use line-height about 1.1–1.3. `blockquote` shares the `h4` scale.
