# Aura + @shadcn/lint

## Installation
```bash
pnpm dlx shadcn@latest add @aura/rule-shadcn-lint
```
`@shadcn/lint` is the machine-checkable layer for Aura Tailwind policy. Rules and `DESIGN.md` guide agents; lint tells them how to fix UI.

## Guardrails

* **MUST**: After UI changes, run the project `lint` script (`pnpm lint`) and clear `@shadcn/lint` findings you introduced before finishing. Prefer zero new `shadcn/no-restyle` and `shadcn/no-arbitrary-values` on touched files.
* **MUST**: Prefer theme tokens (`accent-*`, `gray-*`, semantic) over raw palette colors.
* **MUST**: Prefer the Aura 13px spacing scale over arbitrary values.
* **MUST**: Do not restyle design-system components with padding, colors, or typography via `className` — use variants/sizes, or layout/width only.
* **MUST**: Form controls (`Input`, `Textarea`, `SelectTrigger`, `MaskInput`, `SegmentedInput`) own their padding. Call sites use layout/width only.
* **MUST**: Never put `text-sm` / `text-xs` on editable form controls (17px floor).
* **MUST**: Never add horizontal margin to an icon inside `Button` or `Badge`.

## What lint catches

| Rule | Catches |
| --- | --- |
| `shadcn/no-arbitrary-values` | Values off the 13px scale |
| `shadcn/no-raw-colors` | Raw palette instead of tokens |
| `shadcn/no-restyle` | Restyling DS components via `className` |
| `aura/no-icon-margin` | Horizontal margin on icons inside gap-owning controls |

## Execution

Install, ESLint merge, and the post-UI fix loop live in skill `verify-aura-ui`. Do not paste setup recipes into this rule.
