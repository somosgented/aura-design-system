## Rules

These rules define foundations and principles for the Aura Design System. Install them via the registry into `.agents/rules/`. Cursor loads project rules from `.cursor/rules`; `aura blueprint` links that path at `.agents/rules` so there is one copy.

```bash
pnpm dlx shadcn@latest add @aura/rules
```
### [Animation guardrails](/docs/rules/fundation-animations)

Compositor-friendly motion, reduced-motion, theme animation tokens. Detail in DESIGN.md.

### [Aura agent surface](/docs/rules/aura-agent-surface)

Rules hold guardrails; skills hold execution. DESIGN.md is narrative SoT. Upstream shadcn skill is subordinate to Aura Keep invariants.

### [Color guardrails](/docs/rules/fundations-colors)

12-step accent/gray scale and APCA contrast roles. Detail in DESIGN.md §2.

### [DESIGN.md (narrative spec)](/docs/rules/design-md)

Installs the agent rule into .agents/rules and the project root DESIGN.md (narrative spec). Add with shadcn as @aura/rule-design-md.

### [Feature map](/docs/rules/feature-map)

The only project documentation is a feature map in the Obsidian vault, updated in the PR that changes a feature. No progress logs.

### [Form guardrails](/docs/rules/components-forms)

Form and validation guardrails — useFormDynamic, Form, validateFormData (ajv), server actions. Procedures in skill aura-forms.

### [Icon guardrails](/docs/rules/fundation-icons)

Radix icons via className="icon"; no horizontal margins inside gap-owning controls.

### [No code comments](/docs/rules/no-comments)

Fix the root cause instead of commenting on it. Only external constraints, directives, licenses, and generated code carry comments.

### [Product principles](/docs/rules/principles)

Non-visual Aura product principles that constrain product and UX choices.

### [shadcn lint](/docs/rules/shadcn-lint)

Aura @shadcn/lint policy (no arbitrary values, no raw colors, no-restyle). Installs the agent rule into .agents/rules plus eslint.aura-shadcn.mjs. Add with shadcn as @aura/rule-shadcn-lint or @aura/eslint-shadcn-lint.

### [Spacing guardrails](/docs/rules/fundations-layout-spacing)

Enforce Aura 13px spacing for Tailwind v4

### [Typography guardrails](/docs/rules/fundations-typography)

Fluid clamp() type scale and 17px floor for editable form controls. Detail in DESIGN.md §3.
