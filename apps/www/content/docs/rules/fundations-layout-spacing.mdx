# Spacing guardrails

## Installation
```bash
pnpm dlx shadcn@latest add @aura/rule-fundations-layout-spacing
```
`--spacing` is **13px**. Before any `m`/`p`/`gap`/`h`/`w`/`size` utility, compute `unit * 13px` (so `p-4` = 52px, not 16px). Detail in `DESIGN.md`.

* **MUST**: Use the 13px base and 0.5-unit increments only (`1`, `1.5`, `2`, …).
* **NEVER**: Use non-0.5 increments (`0.2`, `1.2`, …) or arbitrary pixel spacing (`p-[16px]`) unless the human explicitly asks.
* **MUST**: Convert “about 20px” to `1.5` (19.5px), not `2` (26px).
* **MUST**: Sections use defined containers (padding, margins, max-width). Prefer ≤ 5 container types per project.
