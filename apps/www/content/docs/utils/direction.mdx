## Installation
Make sure that `namespace` is set in your component.json file. Namespace docs: [Learn more about namespaces](/docs/namespace)
```bash
pnpm dlx shadcn@latest add @aura/direction
```



### Manual

<Steps>
  <Step>
    Install the following dependencies:

    ```bash
pnpm install radix-ui
    ```
  </Step>
  <Step>
    Copy and paste the Direction component into your `components/ui/Direction.tsx` file.

```tsx
"use client";
/**
 * @description Sets reading direction for Radix primitives and the subtree.
 */
import * as React from "react";
import { Direction } from "radix-ui";

function DirectionProvider({
  dir = "ltr",
  children,
  className,
  ...props
}: React.ComponentProps<typeof Direction.Provider> & {
  className?: string;
}) {
  return (
    <Direction.Provider dir={dir} {...props}>
      <div dir={dir} data-slot="direction" className={className}>
        {children}
      </div>
    </Direction.Provider>
  );
}

export { DirectionProvider };

```
  </Step>
</Steps>
