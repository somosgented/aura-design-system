Not defined yet.

The Apple catalog links this category to Human Interface Guidelines charting guidance. Aura has no chart palette, axis type scale, series order, or annotation rule in tokens, Stylus, lint, or `DESIGN.md`.

`@aura/data-grid` is a table component for dense records. It is documented with the component catalog and with the type and spacing rules for cells (`text-sm` body, uppercase tracked headers, `px-1` or `px-1.5` row padding, `ui-monospace` for identifiers). Those are grid rules, not a visualization system.

When a chart foundation exists, it should land here as tokens and rules taken from the codebase, the same way [Color](/docs/foundations/color) and [Typography](/docs/foundations/typography) do.
